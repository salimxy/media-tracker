📊 Flux de données

  1. N8N collecte les articles RSS toutes les 2 heures
  2. Les articles sont stockés dans PostgreSQL
  3. N8N déclenche l'analyse IA (OpenRouter) sur les nouveaux articles
  4. Les résultats d'analyse sont sauvegardés dans la base
  5. Le Backend API expose les données via REST
  6. Le Frontend affiche les articles et analyses
  7. N8N envoie les notifications email quotidiennes

🎯 Prochaines Étapes

  1. Connectez-vous à N8N et vérifiez que les workflows sont actifs
  2. Testez la collecte RSS en déclenchant manuellement le workflow
  3. Configurez les sources RSS personnalisées dans sources-rss.json
  4. Testez l'analyse IA avec OpenRouter
  5. Configurez les notifications email pour vos clients
  6. Sécurisez l'installation avec HTTPS (Let's Encrypt)
  7. Configurez les backups automatiques de PostgreSQL
  8. Ajoutez des utilisateurs et clients dans la base de données

🔧 Dépannage Rapide

❓ Un service ne démarre pas?
Vérifiez les logs: docker-compose logs [service_name]
❓ Erreur de connexion PostgreSQL?
Vérifiez que le mot de passe dans .env est correct et que le service est démarré
❓ N8N ne collecte pas les articles?
Vérifiez les credentials PostgreSQL et OpenRouter dans N8N
❓ Le Frontend ne se connecte pas au Backend?
Vérifiez que API_URL dans .env pointe vers la bonne adresse
✅ Besoin d'aide?
Consultez les logs détaillés dans ./logs/ ou relancez les scripts de test
